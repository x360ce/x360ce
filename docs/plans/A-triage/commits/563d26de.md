# 563d26de — Converting Axis Map control from Windows Forms to WPF.

- **Date:** 2021-03-17  |  **Risk (A.1):** HIGH
- **Files:** WPF axis-map conversion plus shared JocysCom files

## Changes

### Fixes
- `KeyValue.cs` and `LinkItem.cs` are `[Serializable]` and expose a
  `PropertyChanged` event. A serializable class serializes its event's delegate
  chain, so serializing an instance that has a subscriber drags the subscriber
  in and throws (CWE-502). Added `[field: NonSerialized]`.

### Not portable
- The Axis Map WPF conversion itself, plus `SettingName` entries commented out
  for the rewritten UI.

## Backward compatibility for 4.17.x
Both shared files exist in the restored tree with matching pre-images. The
attribute only affects binary serialization; XML serialization already ignored
events.

## Decision
**Partial — applied.** Attribute applied to all three `PropertyChanged` events
(two in `KeyValue.cs`, one in `LinkItem.cs`); the WPF conversion stays out.
