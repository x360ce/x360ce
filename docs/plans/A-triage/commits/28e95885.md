# 28e95885 — Add forms control support to mem leak test. Fix couple crashes.

- **Date:** 2022-11-01  |  **Risk (A.1):** MEDIUM
- **Files:** memory-leak test infrastructure, `ErrorReportControl.xaml.cs`, `ZipStorer.cs`

## Changes

### Fixes
- `ErrorReportControl.RefreshErrorsComboBox` listed `*.htm` files in the logs
  folder without checking that the folder exists. The folder is created when
  the first error is written, so opening the error report window on a clean
  installation threw `DirectoryNotFoundException`.
- `ZipStorer.Close()` dereferenced `ZipFileStream` before checking it. A second
  `Close()` — or `Dispose()` after an explicit `Close()` — threw
  `NullReferenceException`.

### Not portable
- Memory-leak test harness for WPF windows.

## Backward compatibility for 4.17.x
Both files are shared JocysCom code present in the restored tree and both
pre-images match. `ZipStorer` is used by `Zip.cs` (log/report archives) and by
`VirtualDriverInstaller` when extracting ViGEmBus files.

## Decision
**Partial — applied.** Both crash guards applied; the test harness is not
ported.
