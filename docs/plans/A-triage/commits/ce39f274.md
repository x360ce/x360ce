- **Date:** 2022-10-17  |  **Risk (A.1):** LOW

## Changes

### Fixes
- `Downloader.LoadAsync` sets `retryTimer.Interval` while the timer may be
  running; `System.Timers.Timer` restarts its interval countdown when Interval
  changes on an enabled timer, so retries could fire on stale schedules. Adds
  `retryTimer.Close()` before the Interval assignment so `Start()` re-arms cleanly.

## Backward compatibility for 4.17.x
- Pre-image matches the restored tree exactly. Downloader is the shared cloud/
  update download path used by the WinForms app.
