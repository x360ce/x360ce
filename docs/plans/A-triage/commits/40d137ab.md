# 40d137ab — Update shared files

- **Date:** 2022-10-24  |  **Risk (A.1):** MEDIUM
- **Files:** 8 JocysCom shared files (Helper, Effects.Resize, SocketServer, Serializer, ...)

## Changes

### Fixes
- `SocketServer` changed `keepAliveTimer.Interval` while the timer was running.
  `System.Timers.Timer` restarts its countdown when `Interval` is assigned on an
  enabled timer, so the keep-alive fired on a stale schedule. Added
  `keepAliveTimer.Close()` before the assignment — the same defect and the same
  fix as ce39f274 in `Downloader`.
- `Effects.ResizeWidth` / `ResizeHeight` computed the aspect ratio as
  `width * (image.Height / image.Width)`. Integer division makes the bracket 0
  for any landscape image, so the resulting height was 0 and `Resize` threw.
  Reordered to `image.Height * width / image.Width`.

### Not portable
- `IsOverlap`, XML `NewLineHandling`/`IgnoreWhitespace` serializer changes, and
  general shared-library churn — refactor and feature work, no defect evidence.

## Backward compatibility for 4.17.x
Both fixed files are in the restored tree with matching pre-images.
`SocketServer` backs the remote-controller service (`Global.RemoteServer`).
`ResizeWidth`/`ResizeHeight` currently have no call site in x360ce; the fix is
kept because the defect is unambiguous and the change is one line each.

## Decision
**Partial — applied.** Two fixes applied; the rest of the shared-file sync is
not ported.
