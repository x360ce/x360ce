#### x360ce • Xbox 360 Controller Emulator

Lets a controller (gamepad, joystick, steering wheel, pedals and so on) work on a PC as an Xbox 360 controller.

- Homepage: <https://www.x360ce.com>
- GitHub: <https://github.com/x360ce/x360ce>
- Forum: <https://www.ngemu.com/forums/x360ce.140/>
- Developer: Jocys.com, <https://www.jocys.com>
- Developer: ToCA EDIT, <http://www.tocaedit.com>
- Developer: Nucleoprotein, <https://github.com/Nucleoprotein>
- Developer: jbienz, <https://github.com/jbienz>
- Developer: Squall-Leonhart, <https://github.com/Squall-Leonhart>

#### ViGEm • Virtual Gamepad Emulation Bus

Creates the virtual Xbox 360 controllers that DirectInput devices, a keyboard or a mouse are mapped to.

- Homepage: <https://docs.nefarius.at/projects/ViGEm/>
- GitHub: <https://github.com/nefarius/ViGEmBus>
- Developer: Nefarius, <https://github.com/nefarius>

#### HID Hide • Human Interface Device Hide

Hides the original controllers from games, so that games see only the virtual ones.

- GitHub: <https://github.com/nefarius/HidHide>
- Developer: Nefarius, <https://github.com/nefarius>

#### SDL_GameControllerDB • SDL's controller database

Says which button, stick and hat of a controller is which part of a gamepad. Auto Preset and the SDL pages read it.

- GitHub: <https://github.com/mdqinc/SDL_GameControllerDB>
- Licence: zlib, <https://github.com/mdqinc/SDL_GameControllerDB/blob/master/LICENSE>
- Developer: Sam Lantinga and contributors

#### Selawik • interface font

An open font made to the measures of Segoe UI, which x360ce's windows are written in where Windows has no Segoe UI, or when it is chosen.

- GitHub: <https://github.com/microsoft/Selawik>
- Licence: SIL Open Font License 1.1, <https://openfontlicense.org>
- Developer: Microsoft

#### Inconsolata • code font

A font whose letters line up, for formulas, presets and values.

- GitHub: <https://github.com/googlefonts/Inconsolata>
- Licence: SIL Open Font License 1.1, <https://openfontlicense.org>
- Developer: The Inconsolata Project Authors
